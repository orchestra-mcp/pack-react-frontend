# orchestra-mcp/pack-react-frontend

React and TypeScript frontend skills with shadcn/ui and Tailwind CSS

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-react-frontend
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-react-frontend")
```
